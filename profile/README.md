# StockRush

**[StockRush](https://stockrush.org)** is a marketplace for digital goods — social media and messenger accounts, subscriptions, software keys and gift cards from verified sellers, with instant delivery and buyer protection.

## Open source

- **[netscape-to-json](https://github.com/stockrush-org/netscape-to-json)** — convert Netscape `cookies.txt` to JSON (Cookie-Editor / antidetect format) and back. Zero dependencies.
